# Healthy Living | SEO-Optimized Fitness Blog

This is a complete, production-ready, responsive static blog website created for an SEO practical assessment.

## Project Overview
- **Objective:** Create a static blog containing a fully SEO-optimized article on the benefits of regular exercise.
- **Live URL:** [https://ishowdrift.github.io/seo-fitness-blog/](https://ishowdrift.github.io/seo-fitness-blog/)

## Features
- Clean, minimal, and professional design
- Fully responsive (Mobile-first CSS)
- SEO-optimized with proper meta tags (Title, Description, Open Graph, Twitter Card, Canonical URL)
- Structured Data (JSON-LD) for BlogPosting
- robots.txt and sitemap.xml included
- Semantic HTML and accessibility features

## File Structure
The project uses a simple, static HTML/CSS/JS file structure, easily hosted on GitHub Pages with no build steps required.

## Local Development
To run this project locally, simply clone the repository and open `index.html` in your browser, or use a local development server like Live Server for VS Code.
